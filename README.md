# Scarface Code Website

A responsive, static marketing and download website for [Scarface Code Android](https://github.com/Black7i77/Scarface-Code).

## Preview locally

Open `index.html` in your browser, or run `python3 -m http.server 8080` in this folder and visit `http://localhost:8080`.

## Publish with GitHub Pages

1. Create a public GitHub repository named `Scarface-Code-Website`.
2. Push the contents of this folder to the repository's `main` branch.
3. Open repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. Your expected Pages URL is `https://black7i77.github.io/Scarface-Code-Website/` after GitHub Pages deploys.

## APK download

The website currently links to the **v0.1.0 GitHub release page**, not an assumed direct APK asset. Publish and verify an APK asset in the release before advertising a working download. If you want a direct-download button later, update `#apk-download` in `index.html` to the exact verified asset URL.

## Screenshots

The device display on the site is an **illustrative HTML mock-up**, not an actual screenshot. Replace it with your own Android screenshots after checking they don't contain private data.
