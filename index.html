01 / THE WORKSPACE

Everything you need to stay in the flow.

A desktop-inspired editing experience adapted for touchscreens and external keyboards.

⌘

Code editing

Syntax highlighting, useful coding shortcuts, multiple tabs and find/replace for supported text files.

▣

File management

Create, open and save files with Android's document picker and keep track of unsaved edits.

▶

Local execution

Bundled Python and plain JavaScript runtimes, with an output panel for results and errors.

◈

Offline by design

No sign-in, telemetry or internet permission required by the installed application.

⌨

Made for Android

Touch-friendly controls, coding symbol shortcuts and support for external keyboards.
